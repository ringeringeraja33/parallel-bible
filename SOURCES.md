# Sources, versions and reuse

Recorded on 2026-10-02. Bible text, editorial decisions and source datasets have separate provenance. Hashes of the files read during this review are in [upstream-checksums.json](Audit/upstream-checksums.json). The compressed snapshots under `data/` retain the inputs actually used by the portable builder, not future content at a moving URL.

## Digital Bible witnesses

- English: [CrossWire KJV module](https://www.crosswire.org/sword/modules/ModInfo.jsp?modName=KJV), acquired as [scrollmapper KJV.json](https://github.com/scrollmapper/bible_databases/blob/e1b254cef86d0e65b1a5d1a94b8b112d0f296a2c/formats/json/KJV.json). Its text, spelling, superscriptions and subscriptions are preserved after whitespace normalization.
- Chinese: [CrossWire ChiUns information](https://www.crosswire.org/sword/modules/ModInfo.jsp?modName=ChiUns) describes the public-domain Union Version tradition. The actual file used here is the traditional-character [scrollmapper ChiUn.json](https://github.com/scrollmapper/bible_databases/blob/e1b254cef86d0e65b1a5d1a94b8b112d0f296a2c/formats/json/ChiUn.json), not that simplified module download. OpenCC `t2s` converted it to simplified characters; segmentation whitespace and `<WAHb>` morphology markup were removed. Literal `a` / `并入上节` placeholders become explicit joins; John 7:53 joins John 8:1. Source 3 John 1:15 is preserved in KJV 1:14; source Revelation 12:18 is preserved with KJV 13:1. The transformed source and these decisions are retained in `data/`.
- French, German, Italian, Latin: [midvash/bible-data at d9fe17794477](https://github.com/midvash/bible-data/tree/d9fe1779447717bbfcb578e505b893125cad581c/versions), respectively `fr/lsg`, `de/luth1912`, `it/diodati`, `la/vulg`. The provider labels these Louis Segond 1910, Lutherbibel 1912, Diodati 1649 and Biblia Sacra Vulgata. Metadata give limited details of the underlying printed witnesses; these labels do not establish a critical edition. The earlier downloaded four JSON files were the starting text witnesses; the recorded revision and hashes make the later source check reproducible.
- Latin supplements: [CrossWire Vulgate information](https://www.crosswire.org/sword/modules/ModInfo.jsp?modName=Vulgate) and [scrollmapper Vulgate.json](https://github.com/scrollmapper/bible_databases/blob/e1b254cef86d0e65b1a5d1a94b8b112d0f296a2c/formats/json/Vulgate.json). Only Ruth 4:22 and Amos 9:15 were imported from this additional witness. Other differences were not silently overwritten. Eleven absent slots remain explicitly recorded.

French doubled apostrophes are normalized to single apostrophes; Latin percent-sign word markers and sentence-initial case follow documented display normalization. Italian supplied-word brackets, German original reference markers, and the wording of each source segment remain. Cross-verse segments are shown once with links; Latin source material outside KJV coordinates is preserved in the appendix.

## Canon, versification and names

- Canonical chapter and verse counts: [CrossWire JSword SystemKJV.java](https://github.com/crosswire/jsword/blob/a2c51f3c3a55416f3c991a67ef3d635c7ee55330/src/main/java/org/crosswire/jsword/versification/system/SystemKJV.java). Chapter counts are stored as factual reference data, with this attribution.
- Versification: [STEPBible TVTMS](https://github.com/STEPBible/STEPBible-Data/blob/b99716b0cddb648ddb95cc786a197180f2f97d48/Versification/TVTMS%20-%20Translators%20Versification%20Traditions%20with%20Methodology%20for%20Standardisation%20for%20Eng%2BHeb%2BLat%2BGrk%2BOthers%20-%20STEPBible.org%20CC%20BY.txt). Its conditional mappings were evaluated against the actual source texts, then reviewed; local exceptions are identified in `Audit/alignment-overrides.json`. Fixed source-to-target results are in `data/alignment.json.gz`. There is no claim that applying an entire language's default numbering system is sufficient.
- Proper-name identities, categories, short source descriptions and verse references: [STEPBible TIPNR](https://github.com/STEPBible/STEPBible-Data/blob/b99716b0cddb648ddb95cc786a197180f2f97d48/Proper%20Nouns/TIPNR%20-%20Translators%20Individualised%20Proper%20Names%20with%20all%20References%20-%20STEPBible.org%20CC%20BY.txt). The source dataset distinguishes individuals and locations. This project groups entries by English headword while retaining source identity identifiers and separate records. Descriptions are attributed source descriptions, not newly researched biographies.
- Existing local `biblical_dictionary.csv` supplied candidate spellings only. Its original publication source is **not established** in this review; it is not an authority for identifying persons. A spelling is linked only with independent TIPNR verse evidence. Latin spellings use a limited explicit list, constrained by the same verse evidence. Unverified forms remain unlinked. The original CSV is not redistributed here.

**STEPBible attribution:** Data created by www.STEPBible.org based on work at Tyndale House Cambridge, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Changes in this project: selection to the 66-book scope, normalization of identifiers, grouping and presentation, candidate-spelling filtering, reviewed mapping exceptions, and Chinese editorial explanations. For source updates use the linked upstream datasets. This project does not reproduce the source's longer generated articles.
